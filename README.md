# سیستم مدیریت مراجعه‌کنندگان مطب دکتر بهامین جهانیان

برنامه سبک و تحت شبکه داخلی (LAN) برای مدیریت نوبت‌ها، لیست مراجعه‌کنندگان، ثبت یادداشت و آپلود مدارک و آزمایش‌های بیماران (از کامپیوتر و دوربین گوشی موبایل) با قابلیت بروزرسانی مستقیم از GitHub.

## امکانات اصلی
- **همگام‌سازی زنده بین منشی و پزشک:** هر تغییر بدون نیاز به رفرش در سیستم دیگر دیده می‌شود.
- **یک دیتابیس متمرکز (`data/clinic.db`):** بدون تداخل و نیاز به Merge.
- **آپلود آزمایش و چکاپ با دوربین گوشی (QR Code):** اسکن کد اختصاصی هر بیمار با گوشی در وای‌فای مطب و ارسال فوری عکس یا PDF.
- **پنجره مستقل ویندوزی:** اجرا در حالت App Mode بدون نوار آدرس مرورگر.
- **بروزرسانی با یک کلیک از گیت:** از بخش «بکاپ و گیت» داخل برنامه.

## نصب روی سیستم سرور (سیستم منشی)
1. فایل `install.bat` را اجرا کنید (در صورت نبودن Git یا Node.js، به‌صورت خودکار نصب می‌شوند).
2. از روی دسکتاپ روی **«مدیریت مطب دکتر جهانیان»** کلیک کنید.

## اتصال سیستم پزشک
1. در سیستم منشی روی دکمه **«شبکه مطب»** کلیک کنید و آی‌پی نمایش‌داده‌شده (مثلاً `192.168.1.10`) را ببینید.
2. روی سیستم دکتر فایل `doctor-shortcut.bat` را اجرا کنید و همان آی‌پی را وارد کنید تا میانبر دسکتاپ ساخته شود (نیازی به نصب Node یا Git روی سیستم دکتر نیست).
